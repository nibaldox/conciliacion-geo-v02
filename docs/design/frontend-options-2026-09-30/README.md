# Opciones para el frontend

Fecha: 30 de septiembre de 2026.

Tres propuestas visuales generadas con la herramienta integrada `image_gen`, en modo `ui-mockup`. Los datos de las imágenes son ilustrativos. Son referencias de diseño para elegir la dirección de implementación; no son capturas de un frontend ya modificado.

| Opción | Organización | Uso principal |
|---|---|---|
| 1. Clara corporativa | Navegación lateral única, perfil y tabla juntos | Lectura rápida de valores y presentación convencional |
| 2. Oscura analítica | Perfil amplio, inspector de banco y tabla inferior | Análisis continuado con herramientas visibles |
| 3. Flujo guiado | Etapas horizontales y pestañas de resultados | Orientación del usuario y mayor espacio de análisis |

El usuario eligió la opción 2, oscura analítica. La implementación local sigue esa propuesta y conserva las columnas de diseño y terreno.
